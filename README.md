# مُزيل · Muzeel

أداة عربية لإزالة خلفية الصور بالذكاء الاصطناعي. المعالجة تتم **داخل متصفح المستخدم**، فالصور لا تغادر جهازه، والنتيجة بالدقة الأصلية بدون علامة مائية وبدون تسجيل دخول.

An Arabic-first AI background remover that runs **in the browser**. Images never leave the device, output keeps the original resolution, no watermark, no sign-up.

---

## كيف يعمل · How it works

```
صورة  ──►  BiRefNet_lite (ONNX, WebGPU)  ──►  قناع 1024²  ──►  تكبير + تنعيم  ──►  PNG شفاف بالدقة الأصلية
```

- **المحرك المحلي** — `BiRefNet_lite` بصيغة ONNX (أوزان fp16، مدخلات/مخرجات fp32) يعمل داخل Web Worker عبر `onnxruntime-web` على WebGPU. يُنزَّل مرة واحدة (114 ميجابايت) ويُحفَظ في Cache API.
- **المحرك السيرفري** (اختياري) — BiRefNet الكامل بدقة 2048 عبر `fal-ai/birefnet/v2`، لجودة حواف أعلى.

### سياسة التوجيه

النموذج المحلي كبير، وتنزيله قبل أول نتيجة يعني انتظاراً طويلاً لزائر جديد. لذلك:

| الحالة | المسار |
| --- | --- |
| أول صورة، والخادم مُفعّل | الخادم — نتيجة فورية، والنموذج يُنزَّل في الخلفية |
| النموذج محفوظ في المتصفح | محلي — فوري، مجاني، بدون إنترنت |
| لا WebGPU | الخادم، أو رسالة واضحة إن لم يكن مُفعّلاً |
| فشل المحرك المحلي (شبكة/تشغيل) | يسقط تلقائياً إلى الخادم إن كان متاحاً |

**بدون أي إعدادات، الموقع يعمل بالكامل محلياً.** متغيرات البيئة تضيف مسار الجودة العالية فقط.

## التشغيل · Getting started

```bash
npm install
npm run dev          # http://localhost:3000  →  يحوّل إلى /ar
```

```bash
npm run build        # بناء الإنتاج
npm run typecheck    # tsc --noEmit
npm run lint
npm run test:e2e     # يحتاج npm run dev يعمل في نافذة أخرى
```

`prebuild`/`predev` ينسخان ثنائيات ONNX Runtime إلى `public/ort/` (`scripts/copy-ort-assets.mjs`) — نستضيفها ذاتياً لأن ذلك ما يجعل العمل بدون إنترنت ممكناً.

### الإعدادات

انسخ `.env.example` إلى `.env.local`. كلها اختيارية — انظر التعليقات داخل الملف.

> ⚠️ لو فعّلت `FAL_KEY` في الإنتاج فاضبط Upstash معه. المسار السيرفري بلا مصادقة، وبدون حد معدّل مشترك سيستنزف رصيدك. الحد الاحتياطي في الذاكرة لا يعمل عبر عدة نسخ serverless.

## قرارات تقنية · Technical decisions

**الترخيص أولاً.** أغلب أمثلة إزالة الخلفية في المتصفح — بما فيها [addyosmani/bg-remove](https://github.com/addyosmani/bg-remove) — تستخدم `briaai/RMBG-1.4`، وهو **CC BY-NC**: ممنوع تجارياً بدون ترخيص مدفوع. مُزيل يعتمد [BiRefNet](https://github.com/zhengpeng7/birefnet) حصراً (**MIT**). لا تستبدله بـ RMBG.

**المخرج logits لا احتمالات.** الرسم البياني المُصدَّر ينتهي بـ `Conv` بلا تفعيل، فلازم `sigmoid` في JS قبل استخدام القيم كقناع ألفا (`src/lib/bg/worker.ts`).

**لا ترويسات COOP/COEP.** العزل عبر المصادر يفتح WASM متعدد الخيوط، لكنه يكسر الأدوات المضمّنة (Turnstile) والموارد الخارجية. الاستدلال يعمل على WebGPU وهو أسرع بكثير من WASM متعدد الخيوط أصلاً، فالمقايضة رابحة بوضوح.

**فحص WebGPU بطلب محوّل فعلي.** `'gpu' in navigator` لا يكفي: البيئات البرمجية تُظهر الخاصية وترجع `null` عند `requestAdapter()` — وكنا سنبدأ تنزيل 114 ميجابايت لمحرك لا يمكنه العمل.

**القناع لا يُخزَّن بالدقة الكاملة.** النموذج لا ينتج أكثر من 1024 بكسل من التفاصيل، فتخزين قناع بدقة 30 ميجابكسل يكلّف 120 ميجابايت من الذاكرة مقابل صفر جودة. نحدّه عند 2048 ونكبّره عند التصدير.

**تسوية الحواف يدوية لا بمرشّحات CSS.** `brightness`/`contrast` في `canvas.filter` تعمل على RGB فقط ولا تمسّ ألفا — والقناع يعيش في قناة ألفا. لذلك التنعيم يمر عبر GPU (`blur`) بينما التضييق/التوسيع يمر عبر جدول بحث من 256 مدخلاً في JS، ولا يُعاد حسابه إلا عند تغيّر الإعدادات فعلاً.

**مهلة للتوقف في تنزيل النموذج.** بدونها يترك الاتصال المحجوب أو نصف المفتوح المستخدم أمام شريط تقدّم لا ينتهي، بلا خطأ وبلا بديل.

## البنية · Structure

```
src/
  app/[locale]/               صفحة عربية/إنجليزية مع RTL كامل
  app/api/remove-background/  مسار fal.ai + حد المعدّل + التحقق من الملف
  components/Studio.tsx       آلة الحالة: عرض → معالجة → محرر
  components/editor/          لوحة العرض واللوحات الجانبية
  lib/bg/
    worker.ts                 الاستدلال داخل Web Worker
    remove.ts                 اختيار المسار والسقوط الاحتياطي
    compose.ts                تنعيم القناع + التركيب + الظل
    export.ts                 التصدير بالدقة الكاملة
  lib/i18n/                   قاموس النصوص
tests/e2e.mjs                 اختبار المحرر كاملاً (بيانات مولّدة، بلا ملفات ثابتة)
```

## الاختبار · Testing

الاستدلال نفسه يحتاج WebGPU، وهو غير متاح في Chromium بلا واجهة، لذلك `tests/e2e.mjs` يستبدل `/api/remove-background` بقناع معروف ويفحص كل ما بعده: استخراج القناع، التنقيح، الفرشاة، التراجع، التركيب، والتصدير. الصور التجريبية تُولَّد داخل المتصفح فلا يحمل المستودع أي ملفات ثنائية للاختبار.

خط أنابيب النموذج نفسه تم التحقق منه بأوزان حقيقية: المخرج بعد `sigmoid` يعطي 74% خلفية واثقة و25% مقدمة واثقة و0.9% منطقة انتقالية — وهو ما ينتجه المتصفح بالضبط.

## الحدود المعروفة · Known limitations

- المسار المحلي يحتاج **WebGPU** (Chrome/Edge حديث، Safari 26+، Firefox 141+). بدونه يتحوّل للخادم، أو يعرض رسالة واضحة.
- حد الإدخال 30 ميجابايت و30 ميجابكسل.
- المعالجة الدفعية والصيغ المتحركة غير مدعومة بعد.
